One funny honest appliance error line: a washing machine's flat, put-upon
report of an unbalanced load.

Entry for [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) on make.fun.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`
when set). Python 3 standard library only, no dependencies.
